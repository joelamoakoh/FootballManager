# Football Manager

# Created a football manager app using kotlin

## Features
- Add players
- List players
- Find players
- Update players
- Delete players
- List players by position

## Player Information
Each player has:
- Name
- Position
- Squad number
- Age
- Appearances

## Match Information
- Opponent
- Date
- Competition
- Score
- Home matc


##  Used technologies
- Kotlin
- Gradle
- JUnit
- JaCoCo
- Dokkak
- GitHub

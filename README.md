# Football Manager

# Created a football manager app using kotin

## Features
- Add players
- List players
- Find players
- Update players
- Delete players
- List players by position

## Player Information
Each player has:
- Name
- Position
- Squad number
- Age
- Appearances


##  Used technologies
- Kotlin
- Gradle
- JUnit
- JaCoCo
- Dokkak
- GitHub
